# SOLIDWORKS CAD, Fixture & Shop DFM Rules

Follow these engineering defaults whenever creating, inspecting, refactoring, or auditing SOLIDWORKS models in this shop:

## 1. Domain Unit System Discipline (Mandatory)
Always configure and verify the SOLIDWORKS document unit system before sketching or dimensioning:
- **`MMGS` (millimeter, gram, second)** for:
  - All **3D-printed parts** (including airflow/dust/air-blast lofts and nozzles),
  - All **Gridfinity** bins, baseplates, and toolholders,
  - All **KiCad PCB enclosures**, light pipes, and SMD reflow/soldering/pogo fixtures.
- **`IPS` (inch, pound, second)** for:
  - All **woodworking** parts and custom furniture assemblies,
  - All **CNC furniture parts & shop jigs/fixtures** (including `1/2"` Corian vacuum pods and QCW dowel fixtures),
  - All **residential / shop electrical cutouts** integrated into woodwork,
  - **SendCutSend** imperial gauge parts.
- *Internal API reminder*: SOLIDWORKS COM calls always accept lengths in **meters** and angles in **radians**; convert explicitly and never mix display units blindly. Check `IAssemblyDoc.AddMate5` success against `swAddMateError_e.swAddMateError_NoError` (`1`, **not** `0`), read `IComponent2.Transform2.ArrayData` / `ISketch.ModelToSketchTransform.ArrayData` once for pure C# matrix transforms (`AssemblyGeometryHelper.TransformPointFast` / `SwHelper.ProjectModelToSketch2D` / `SwHelper.ProjectModelMmToSketch2D`) instead of calling `IMathUtility.CreatePoint` + `IMathPoint.MultiplyTransform` inside open sketches or face loops.

## 2. Manufacturing Preference & Cost/Lead-Time Hierarchy
Default to fast, low-cost in-house fabrication before considering external vendors:
1. **Tier 1 (Preferred — Fast, Low-Cost In-House)**: Power-tool woodworking, 3D printing (`MatterHackers Tough PLA Basic` on Prusa MK3.5S+ w/ `0.4 mm` nozzle — check thermal $T_g$/sagging `>45°C`, cold creep under sustained preload/clips, abrasion, and sliding friction in `dfm-3d-printing`), and CNC carving (`Onefinity Elite Journeyman Gen 2`).
2. **Tier 2 (Specialty / Higher-Cost In-House)**: `1/2" Corian` + `MMA structural glue` (for extreme rigidity or vacuum-impermeable CNC pods/jigs), `MatterHackers Tough PLA Pro` (only when impact/mechanical stress justifies extra cost), `4"` / `1/8"` acrylic, and secondary filaments (`PLA` -> `PETG`/`Transparent PETG` -> `PVB`/`CPE`/`ASA`/`TPU` -> last-resort `Prusament PC`).
3. **Tier 3 (Deprioritized External Vendor — Expensive & Slow)**: **SendCutSend** laser cutting and sheet metal. Use ONLY when metal stiffness, heat/wear resistance, thin-wall structural profiles, or brass/copper/stainless hardware aesthetics are strictly required. Minimize costly vendor secondary operations (bending, countersinking, tapping, PEM insertion) when a flat plate or in-house Portaband/Angle Grinder/countersink work suffices.
4. **Tier 4 (Rare Last Resort)**: External CNC machine shop (supported with formal 2D drawings & GD&T callouts).

## 3. Multimodal Design Intent, Visual Self-Verification & Clean Viewport
- When given a **photo or hand sketch**, use multimodal reasoning to infer true engineering intent (orthogonality, symmetry, load paths, clearances, mounting datums, airflow continuity) rather than blindly tracing distorted perspective pixels. Use `sw_insert_sketch_picture` only when tracing a literal 2D organic contour.
- **Batch-First Execution, Sequential COM & Assembly Phases**:
  - Prefer **`sw_build_part_features`** (supports `op`: `ref_plane`, `sketch_2d`, `sketch_3d`, `extrude`, `revolve`, `hole_wizard`, `hole_preset`, `fillet`, `chamfer`, `shell`, `pattern`, `mirror`, `label`, `teardrop`, `crisscross_bridge`, `joinery`, plus `auto_fully_define`) or batch `sketches` / `operations` / `items` / `routes` / `target_docs` arrays to create or rebuild a multi-feature part in one call instead of sequential sketch->extrude->cut turns. On assemblies, prefer **`sw_manage_assembly_components(action="pose_and_mate_batch" | "batch")`** with geometric selectors (`entity_a_spec` / `entity_b_spec`, `principal_planes`) or **`SwHelper`** inside `sw_execute_csharp`. Cap raw COM selector string retries at **1** before switching to geometric face/plane lookup (`entity_a_spec` / `SwHelper.FindPlanarFace` / `SwHelper.FindCylindricalFace`). Prefix strict top-level component lookups with **`@top:`** or **`/`** when subassemblies contain duplicate filenames.
- **Design-Intent Sketch Constraints & In-Context Boundary (`FullyConstrained = 3`)**:
  - Always express design intent cleanly before closing 2D sketches: anchor to Origin/datums/centerlines -> apply geometric relations (`Symmetric`, `Equal`, `Concentric`, `Colinear`, `Coincident`, `Midpoint`, `Tangent`, `Horizontal`, `Vertical`) -> apply **named & equation-derived dimensions** (`Plate_Width@Base_Sk`, `="Plate_Width@Base_Sk" / 2`, or external `equations.txt`) -> let `auto_fully_define` (`true` default via `SwHelper.FullyDefineActiveSketch`) lock any residual DOFs. Report `sketch_health` telemetry (`under_defined_sketches`), without blocking `sw_save_document` when the user intentionally leaves a sketch unfinished (`auto_fully_define=false` / `fix_underdefined_sketches=false`).
  - **In-Context Assembly Constraints (`->`)**: Use `IAssemblyDoc.EditPart2` (`SwHelper.BeginEditPartInAssembly` -> `AddInContextRelation` / `ConvertEntitiesInContext` -> `EndEditPartInAssembly`) or `in_context_concentric_targets` on **custom shop-fabricated brackets, adapter plates, clips, cable saddles, and shrouds** so shifting a motor, rail, or switch via assembly mates automatically updates mating holes/edges (applying in-context relations *before* `FullyDefineActiveSketch`). **Never** add in-context external references to **COTS / off-the-shelf parts** (motors, linear rails, bearings, switches, McMaster hardware, vendor `.STEP` files).
- **Mandatory SOLIDWORKS Hole Wizard Rule (`HoleWizard5` / `IWizardHoleFeatureData2` / `sw_hole_preset`)**:
  - Never model screw/bolt clearance holes, counterbores, countersinks, or tapped/self-threaded plastic holes as raw extruded circles. Always use **Hole Wizard** (`sw_hole_preset` or `sw_build_part_features` `op: "hole_wizard" | "hole_preset"`, or `HoleWizard5` + `SwHelper.EditHoleWizardLocations`): specify **`fit`** (`"close"`/`"tight"`, `"normal"`, `"loose"`), match **`hardware_type`** (`"shcs"`, `"bhcs"`, `"hex_bolt"`, `"pan"`, `"flat_head_90"`, `"flat_head_82"`, `"flat_head_100"`), use **`"3dp_self_thread"`** for direct plastic self-threading holes (tuned tap drill + automatic `90°` entry lead-in countersink), and always constrain the **Hole Wizard Location Sub-Sketch (`GetFirstSubFeature()`)** *after* setup.
  - **Exclusive SOLIDWORKS Session Lock & Sequential Tool Execution (Mandatory)**:
    - Before calling any SOLIDWORKS CAD tool, **claim exclusive access** via **`sw_connect_status(lock_action="claim", agent_id="<your Conversation ID>", task="<brief summary of your task>")`**, pass that same **`agent_id`** on every subsequent SOLIDWORKS tool call, and **release it** via **`sw_connect_status(lock_action="release", agent_id="<your Conversation ID>")`** when done (even if switching away or finishing early).
    - If `sw_connect_status` or any tool reports **`locked_by_other_agent=true`** (another agent already owns SOLIDWORKS), **STOP immediately** — do **not** call SOLIDWORKS tools and do **not** use `force_claim` / `force_unlock` on your own. Tell the user which `agent_id`, `task`, and `idle_seconds` / `in_flight_tool` currently hold the lock, and ask whether you should work on something else, wait, or force-override (`lock_action="force_claim"` or `"force_unlock"`). If the user explicitly asks to abort/override a crashed, forgotten, or stuck agent (or runs `scripts\Unlock-SolidWorksMcp.ps1`), call `sw_connect_status(lock_action="force_claim"|"force_unlock", abort_running_worker=true)` (idle forgotten locks also auto-expire after `lease_ttl_seconds`, `900s` default, or auto-clear if the owning supervisor PID exited).
    - NEVER issue parallel SOLIDWORKS MCP tool calls (`sw_open_or_import_document` ×2, `sw_execute_csharp` alongside `sw_search_and_download_mcmaster`, etc.). SOLIDWORKS runs on a single-threaded COM STA; parallel calls contend on the COM thread (`SolidWorksMcpServer` enforces a cross-process COM mutex). Issue SOLIDWORKS tool calls strictly one at a time.
  - **4-Phase Assembly Refactor & Part Post-Delete Rebuild Discipline**: On major assembly refactors (~20+ mate/component changes), separate **delete mates -> delete components -> edit parts -> pose & re-mate** (`sw_manage_assembly_components` auto-flushes an intermediate `EditRebuild3()` between destructive and constructive batch phases to prevent `0x800706BA` solver crashes). Similarly, on **Parts**, never delete features, absorbed sketches, or reference planes via `DeleteSelection2` (especially under `EnableFeatureTree = false` / `SuppressUiUpdates`) and immediately call `InsertSketch(true)` without an intermediate `EditRebuild3()` — doing so leaves dangling `uoSelRefGeom_c` nodes in `uiBlockMan_c::isPartialModify -> uiModelDoc_c::conditionalBlockCmd` (`0x800706BA`). Use `SwHelper.BatchDeleteFeatures(doc, names)` or let `SwHelper.DeleteSelectionSafe` + `SwHelper.InsertSketchSafe` flush `EditRebuild3()` automatically, and never set `EnableFeatureTree = false` (`SuppressUiUpdates`) during part sketch builds.
  - **Bounded Part Builds, `start_offset` / `MakeOffsetPlane`, Checkpointed Saves & Safe Sketch Setup**: Prefer declarative `sw_build_part_features` over monolithic `sw_execute_csharp` part scripts. Save new documents immediately via `sw_create_document(save_path=...)` and checkpoint via `sw_save_document` between phases; bound `sw_execute_csharp` feature builds to **1–3 sketch+feature cycles** per call and pass `use_undo_transaction: false` on multi-sketch construction scripts. Use `start_offset` + `start_offset_mode: "model_positive"` (or `SwHelper.MakeOffsetPlane`) instead of trial `InsertRefPlane -> DeleteSelection2 -> InsertSketch` probes, bake profile chamfers into revolve polylines (or use `sw_fillet_or_chamfer` / `IFace2.GetEdges()`) instead of grazing `SelectByRay` edge loops, keep `sm.AddToDB = false` until *after* `InsertSketchSafe(true)` enters sketch edit mode, and explicitly select the closed sketch (`SelectByID2(skName, "SKETCH", ...)`) before `FeatureExtrusion3` / `FeatureCut4` / `FeatureRevolve2`.
  - **Never Call Crash-Prone Raw APIs**: Never call `ISketchManager.CreateSketchSlot` (crashes `SLDWORKS.exe` `0x800706BE` when `center-to-center < width` — use `SwHelper.CreateSlot2D` / `slot` entities), `ISketchManager.CreatePolygon` (blocked in `sw_execute_csharp` because interactive UI-macro entity creation bypasses `AddToDB` and triggers `uoSelRefGeom_c::getRefGeom` `0x800706BA` crashes — draw N `sm.CreateLine(...)` segments with `AddToDB = true` or use `sw_create_2d_sketch` / `sw_build_part_features`; `CreateCornerRectangle` / `CreateCenterRectangle` are automatically rewritten to `SwHelper.CreateCornerRectangleSafe` / `SwHelper.CreateCenterRectangleSafe` drawing 4 `AddToDB` lines), `IMathPoint.MultiplyTransform` / `IMathVector.MultiplyTransform` (blocked in `sw_execute_csharp` because `IMathUtility.CreatePoint` + `MultiplyTransform` inside active sketches crashes `SLDWORKS.exe` `0x800706BA` / `0x800706BE` in `slduiu:uiModelDoc_c::conditionalBlockCmd` — cache `(double[])sm.ActiveSketch.ModelToSketchTransform.ArrayData` once and use `SwHelper.ProjectModelToSketch2D` / `SwHelper.ProjectModelMmToSketch2D` / `AssemblyGeometryHelper.TransformPointFast`), `ToolsCheckInterference2` (`0x80010105` — use `sw_measure_clearance`), `DisplayDimension2[0]` (`0xC0000005` — use `doc.Parameter("D1@MateName")` or `GetFirstDisplayDimension()`), `.GetWhatsWrong(` (use `sw_audit_assembly_mates`), raw `.Save3`/`.SaveAs*` in `sw_execute_csharp` (use `sw_save_document` / `SwHelper.SaveSilent`), or mix `DeleteSelection2` + `.Reference`/`.ReferenceComponent` in the same script (`0xffffffff` host crash).
  - **Never Force-Kill `SLDWORKS.exe` (3DEXPERIENCE Cloud License Protection — Mandatory)**: Never run `Stop-Process -Force`, `taskkill /F`, or `Process.Kill()` on `SLDWORKS.exe`. Force-killing `SLDWORKS.exe` prevents SOLIDWORKS Connected from checking its seat back into the 3DEXPERIENCE server, triggering a **~15–20 minute 3DEXPERIENCE cloud license lock**. If a modal dialog ever appears, **only dismiss the child popup window via `WM_CLOSE` (`0x0010`) or `Esc` (`VK_ESCAPE`)** (and only close SOLIDWORKS gracefully via `ISldWorks.ExitApp()` / `CloseMainWindow()`) so the 3DEXPERIENCE license lease is never orphaned. (Note: `sw_connect_status(lock_action="force_claim"|"force_unlock", abort_running_worker=true)` only terminates the MCP server's own `SolidWorksMcpServer.exe --worker` child process, never `SLDWORKS.exe`.)
  - **Crash / Timeout Yield & Debug Ticket Protocol (Mandatory)**: When SOLIDWORKS crashes (`0x800706BA`, `0x800706BE`, `0x80010105`, worker crash) or times out, if automatic restart/recovery does not succeed immediately on the first attempt, **stop and yield to the user to intervene** — do not loop on repeated restart retries or risky workarounds. Release the session lock (`sw_connect_status(lock_action="release", agent_id=...)`) and provide a **Debug Bug Ticket** containing enough detail for another agent to debug & fix: (1) target document path and operation context, (2) exact MCP tool name and full JSON arguments / C# snippet, (3) exact HRESULT / exit code / timeout duration plus `crash_journal_path` (`%APPDATA%\SolidWorksMcpServer\crash_journal.jsonl`) and `stderr_tail`, and (4) suspected API trigger and minimal reproduction steps.
- **Hide Created Sketches Before Finishing (Clean Viewport Gate)**: Never leave newly created sketches visible when ending your turn — including 2D/3D reference sketches, layout sketches, and cable/loom/sweep/loft guide paths — once the solid bodies are created. Hide them (`IModelDoc2.BlankSketch()` / `SwHelper.HideSketches(...)`; automatic in `sw_build_part_features` unless `keep_sketches_visible=true`) before capturing final views and finishing. Only leave a sketch visible if **(a)** it was already visible before you started working, or **(b)** the sketch itself is the requested deliverable (e.g., to illustrate an idea, contour, or specific dimensions).
- After creating or significantly modifying 3D geometry, **always call `sw_capture_viewport_quad`** once to visually inspect **all 7 standard views at a minimum (`*Isometric`, `*Top`, `*Bottom`, `*Left`, `*Right`, `*Front`, `*Back`)** and catch flipped extrudes, intersecting flanges, twisted lofts, backside/bottom clearance issues, or misaligned hole patterns on opposite faces before presenting results. On 2D `.SLDDRW` drawings and assembly instruction guides, call **`sw_capture_drawing_sheets`** (or `sw_capture_viewport_quad`, which auto-routes `.SLDDRW` docs to maximized `SaveBMP(path, 0, 0)` sheet capture) to visually inspect every sheet.

## 4. Shared Parameters, Hardware BOMs, Scope-Aware Verification & DFM Gates
- Define common stock thicknesses and `material_thickness + tolerance` derivations in an external linked **`equations.txt`** file so parts across an assembly stay synchronized.
- For hardware assemblies, inspect coaxial hole stacks with `sw_inspect_assembly_joints` (defaulting to `"18-8 Stainless Steel"` unless another material is requested, and choosing the appropriate `nut_style`: `"nylock"`, `"hex_nut"`, or `"jam_nut_stack"`), batch-download & verify genuine McMaster-Carr `.SLDPRT` geometry via `sw_search_and_download_mcmaster` (using the installed McMaster-Carr SOLIDWORKS Add-in bridge), ensure each part has a `"Fastener_Axis"` reference axis, and populate/mate (`Concentric` + `Coincident`, unfixed, unlocked rotation unless hex-flat clocking is required) in `"McMaster Hardware"` via **`sw_install_fastener_stack`** (for complete multi-joint stacks) or `sw_populate_mcmaster_hardware` (single SKU or `items` batch) with `<PartNumber>_<Description>.SLDPRT` naming (`^\d{4,5}[a|k|n|t]\d{1,3}_`). Never synthesize placeholder hardware geometry (`allow_placeholder_generation=false`) without explicit user approval.
- For custom-part BOM descriptions/roles and reference-part BOM exclusion without opening part files in `sw_execute_csharp`, use **`sw_manage_assembly_components(action="configure_bom_and_properties", exclude_from_bom_components=[...], component_properties=[{component_name, properties:{BOM_Desc, BOM_Role, BOM_Category, BOM_Technique, PartNumber, Description}}])`**, and insert/customize drawing BOM tables declaratively via **`sw_insert_bom_table`** (or `sw_create_fabrication_drawing(bom={...})`).
- **Mandatory Canonical BOM Sort Order**: Always sort every BOM (`sw_extract_mcmaster_and_shop_bom`, `sw_insert_bom_table`, `sw_create_fabrication_drawing`, and markdown/table BOMs) in this exact order (`sort_canonical=true` default):
  1. **OEM / COTS Non-Fastener Parts** (`oem` — actuators, motors, linear rails, bearings, valves, switches, PCBs, Blum hardware),
  2. **Parts Manufactured In-House / Custom Fabricated** (`manufactured` — ordered first by **Manufacturing Technique** [`woodworking` -> `3d_printing` -> `cnc_carving` -> `sheet_metal_sendcutsend` -> `custom_fabricated`] and then by **Size** [largest bounding-box volume / max dimension first]),
  3. **Fasteners** (`fastener` — ordered strictly by sub-type: **Threaded Inserts** -> **Screws** -> **Bolts** -> **Washers** -> **Nuts**, and within each sub-type by thread diameter and length).
- Proactively propose **BOM SKU consolidation** across same-thread joints with close grip lengths (e.g., sharing one bolt length across `22.7 mm` and `26.1 mm` M8 stacks when tip clearance allows) and treat undersized blind tap-drill holes in 3D-printed brackets (`~Ø2.05 mm` for M2.5, `~Ø2.50 mm` for M3) without heat-set inserts as direct self-threading plastic taps.
- Verify assembled hardware with scoped, grouped **`sw_measure_clearance(include_components=[...], exclude_same_subassembly_pairs=true, group_by_pair=true)`** (always pass the modified component subset + immediate neighbors or an entity pair; unfiltered all-to-all interference checks are disabled to avoid >3m0s timeouts; check `unexpected_collision_count == 0` while separating expected thread/tap engagement overlaps).
- **Motion Stroke Scope & Abbreviated Iterative Checks**:
  - **Skip `sw_verify_motion_stroke`** completely when edits stay cleanly outside the moving stage's swept bounding box (verify clearance analytically via component bounding boxes / transforms).
  - **During iterative design** on moving slides, armatures, or cable loops, run **`sw_verify_motion_stroke`** with **abbreviated model-discovered geometry stops** chosen by inspecting the shape/viewport: on linear slides test only the 1–2 travel endpoints (often just the **1 affected endpoint** near the edit); on rotating armatures or rolling cable U-loops include 1 endpoint + at most 1 intermediate tightest-bend inflection stop.
  - **At user sign-off or fabrication prep**, run the thorough full-envelope stroke sweep (`[home, mid, soft_max, hard_max]`).
- **Zero Yellow/Red Mates Gate (Mandatory on Assemblies)**: Never leave SOLIDWORKS assembly mates in **yellow (warning)** or **red (error)** states — neither in the top-level assembly nor in loaded subassemblies. Intermediate assembly mutations automatically attach a fast `<5ms` top-level `mate_health` summary; run full **`sw_audit_assembly_mates(include_subassemblies=true)`** once before finishing an assembly edit. Resolve every dangling, over-defined, or unsatisfied mate (repairing or deleting via `sw_manage_assembly_components(action="delete_mates", mate_names=[...])` and re-mating cleanly) until **`clean == true`** (`red_mate_count == 0` and `yellow_mate_count == 0`).
- Before declaring a design manufacturing-ready, read the relevant domain DFM skill (`dfm-3d-printing`, `dfm-cnc-carving`, `dfm-woodworking`, or `dfm-sheet-metal-sendcutsend`) and check against `.agents/plugins/solidworks/data/shop_profile.json` via `sw_audit_dfm`.
- **Manufacturer Datasheet & Spec Verification (Brand/Product Specifics)**: Whenever the user specifies a particular **brand, product, material line, tool, or part number** (e.g., MatterHackers Tough PLA Basic/Pro, Prusament PC, Blum slides/hinges, Onefinity CNC, specific router bits, electronics boards/switches, adhesives, or McMaster-Carr SKUs), proactively look up and cite the **official manufacturer Technical Data Sheet (TDS), dimensional drawing, or spec sheet** (`search_web` / vendor catalog / local `.STEP`) rather than relying on generic category estimates from memory. Clearly distinguish published TDS numbers from general engineering estimates when a spec is not published.

## 5. Fabrication Export Gate (Explicit User Request Only — `.PDF` Documentation Exempt)
> **Export Only on Explicit User Request (`.3MF`, `.STL`, `.DXF`, `.STEP`)**: Never export `.3MF`, `.STL`, `.DXF`, or `.STEP` manufacturing files during design, mating, or DFM iteration. Stop at `.SLDPRT` / `.SLDASM` save (`sw_save_document`) + `sw_audit_dfm` + `sw_capture_viewport_quad`, and export CAM/3D-print/laser fabrication files only when the user explicitly asks to print, CAM, or order parts.
> **Automatic `.PDF` Export for Drawings & Assembly Guides**: `.PDF` drawings and assembly instruction guides are documentation artifacts and are **not** subject to the manufacturing artifact gate — automatically export a multi-sheet `.PDF` (`export_pdf=true` default in `sw_create_fabrication_drawing`, `sw_insert_bom_table`, and `sw_add_drawing_callouts_and_bom`) whenever creating or updating a `.SLDDRW` drawing or assembly guide.
